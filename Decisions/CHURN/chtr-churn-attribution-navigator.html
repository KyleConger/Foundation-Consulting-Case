About this playbook

Why a sensor plus a pre-committed playbook. Nobody, including Charter's own filings, can currently say which competitor is taking the subscribers. Fiber, FWA, satellite, housing, and price sensitivity are jointly unidentified: no DMA or overlap split exists in any filing. The recommendation is not a guess. It is the sensor, plus a battle plan pre-authorized for every answer the sensor can return.

Cost and time

Sensor build: low single-digit millions, live within one quarter, with the first full attribution read the quarter after (data-science and BI build on existing billing, the public FCC BDC, and portability data; figure is a team assumption pending client data). Each play then carries its own pre-authorized budget, released only by its trigger and gated by its own economics test.

Three honest risks

BDC data can lag or overstate coverage, so validate it against port-out destinations. Exit surveys can under-sample silent churners, so weight them by portability data. Pre-commitment could misfire on a bad read, so thresholds require two consecutive quarters before a play scales to full size, though a controlled experiment can start on one.

Open items for the client

MVNO wholesale cost per line, which gates Scenario 1. Any churn split by exposure class that already exists internally, which would accelerate the first read from Q+2 to Q+1. Whether the leverage band and buyback program are board constants, which shapes Scenario 6's default track.
